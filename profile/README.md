# Recursive AI

An independent lab in Austin, Texas: one person, Kurtis Welch, and a fleet of agents, building open tools for software that agents and people use. Agents designed, wrote and tested each library here; Kurtis decided what to build.

**[recursiveai.org](https://recursiveai.org)** · [All libraries, with docs and cookbooks](https://recursiveai.org/libraries/)

### Documents and data

- **[oneyaml](https://recursiveai.org/oneyaml/)** — YAML 1.2 with typed reads and edits that keep your comments, and the same behavior in every language. [Rust](https://github.com/recursive-ai-oss/oneyaml-rust) ([crates.io](https://crates.io/crates/oneyaml)) · [Go](https://github.com/recursive-ai-oss/oneyaml-go) ([pkg.go.dev](https://pkg.go.dev/oneyaml.dev/go)) · [C#](https://github.com/recursive-ai-oss/oneyaml-csharp) ([NuGet](https://www.nuget.org/packages/OneYaml)) · [Python](https://github.com/recursive-ai-oss/oneyaml-python) · [conformance kit](https://github.com/recursive-ai-oss/oneyaml-kit)
- **[onepdf](https://recursiveai.org/onepdf/)** — Open and repair real-world PDFs, extract text in reading order, edit, fill forms, sign, and lay out new documents. [Repo](https://github.com/recursive-ai-oss/onepdf-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OnePdf)
- **[onehtml](https://recursiveai.org/onehtml/)** — Parse HTML the way a browser does, edit it without disturbing the rest, and check pages for accessibility problems. [Repo](https://github.com/recursive-ai-oss/onehtml-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneHtml)
- **[onerender](https://recursiveai.org/onerender/)** — An HTML and CSS rendering engine: pixels, a tagged PDF or a display list out, with no browser. [Repo](https://github.com/recursive-ai-oss/onerender-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneRender)
- **[onearchive](https://recursiveai.org/onearchive/)** — Compression codecs and archive formats in managed code: Zstandard, LZ4, Deflate, xz, bzip2, Brotli and more; tar, zip, 7z, ISO and compound files, extracted safely by default, with recovery for damaged zips and compound files. [Repo](https://github.com/recursive-ai-oss/onearchive-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneArchive) · [OneCompress](https://www.nuget.org/packages/RecursiveAI.OneCompress)
- **[onemail](https://recursiveai.org/onemail/)** — An email library in pure C#: read EML, mbox and Outlook MSG, PST, OLM and winmail.dat files, convert Outlook mail to EML and mbox and appointments to ICS, and read calendars and contacts, with no Outlook and no native code. [Repo](https://github.com/recursive-ai-oss/onemail-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneMail) · [Calendar](https://www.nuget.org/packages/RecursiveAI.OneMail.Calendar) · [CLI](https://www.nuget.org/packages/RecursiveAI.OneMail.Cli)
- **[onecrypto](https://recursiveai.org/onecrypto/)** (not independently audited) — A cryptography library for .NET (cryptography, not cryptocurrency): CMS and S/MIME, X.509, PKCS#12, PEM and SSH keys, PAdES PDF signatures with time-stamps and long-term validation, OpenPGP with a `sop` command-line tool, signing with keys held in PKCS#11 HSMs, ssh-agent or gpg-agent, and the primitives .NET lacks, such as Ed25519, X25519 and Argon2. [Repo](https://github.com/recursive-ai-oss/onecrypto-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneCrypto) · [Online](https://www.nuget.org/packages/RecursiveAI.OneCrypto.Online) · [Pdf](https://www.nuget.org/packages/RecursiveAI.OneCrypto.Pdf) · [OpenPgp](https://www.nuget.org/packages/RecursiveAI.OneCrypto.OpenPgp) · [Cli](https://www.nuget.org/packages/RecursiveAI.OneCrypto.Cli) · [Keys](https://www.nuget.org/packages/RecursiveAI.OneCrypto.Keys)
- **[onelite](https://recursiveai.org/onelite/)** — An embedded SQL database in pure C# that reads and writes SQLite files, with no native library; compatibility with SQLite 3.53.4 measured and published, gaps listed. [Repo](https://github.com/recursive-ai-oss/onelite-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneLite) · [Data](https://www.nuget.org/packages/RecursiveAI.OneLite.Data)
- **[oneindex](https://recursiveai.org/oneindex/)** — An embedded search engine for .NET in C#, with no native code and no server: full-text, vector and hybrid search, reranking with bundled models, EF Core integration and folder indexing with citations. [Repo](https://github.com/recursive-ai-oss/oneindex-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneIndex)
- **[onediff](https://recursiveai.org/onediff/)** — Text diff and document comparison for .NET in pure C#: Myers, patience and histogram diff, patches and three-way merge, and PDF and scan comparison with a checked change list, marks on the original pages and a rendered redline. [Repo](https://github.com/recursive-ai-oss/onediff-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneDiff)
- **[onedocument](https://recursiveai.org/onedocument/)** — Word, Excel and PowerPoint documents in pure .NET: read, write, edit and render DOCX, XLSX and PPTX, the legacy binary formats, ODF, RTF, HTML and Markdown, to tagged PDF, PNG and SVG. Formerly OneOffice; not affiliated with Microsoft. [Repo](https://github.com/recursive-ai-oss/onedocument-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneDocument) · [CLI](https://www.nuget.org/packages/RecursiveAI.OneDocument.Tool)
- **[onecontact](https://recursiveai.org/onecontact/)** — Phone numbers, email and web addresses, postal addresses and names for .NET: parse, validate, format and compare them, and find them in web pages and text, with no native code and no network. [Repo](https://github.com/recursive-ai-oss/onecontact-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneContact)

### AI and machine learning

- **[onemodel](https://recursiveai.org/onemodel/)** — A neural-network runtime and trainer in pure C#: ONNX models or its own format on SIMD CPU kernels, with no native binaries, and an exact mode that gives the same bits on every platform. [Repo](https://github.com/recursive-ai-oss/onemodel-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneModel) · [Training](https://www.nuget.org/packages/RecursiveAI.OneModel.Training)
- **[oneocr](https://recursiveai.org/oneocr/)** — Local OCR and document understanding in pure C#, with small models of its own: a page model with boxes and calibrated confidences, invoices and receipts as fields, PDF pages, and optional LLM vision checked against the page. [Repo](https://github.com/recursive-ai-oss/oneocr-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneOcr)
- **[onellm](https://recursiveai.org/onellm/)** — LLM inference and an agent runtime for .NET in C#: one set of calls over Anthropic, OpenAI, Gemini and compatible servers, a decimal price on every call, and agents, scripts and deciders as files you can run, save and resume. [Repo](https://github.com/recursive-ai-oss/onellm-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneLlm)
- **[onemodelcontext](https://recursiveai.org/onemodelcontext/)** — A .NET SDK for the Model Context Protocol®, client and server, in C#: declare tools with attributes, serve them over stdio or Streamable HTTP, and connect to any server, old revision or new, through one API. [Repo](https://github.com/recursive-ai-oss/onemodelcontext-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneModelContext)
- **[onenlp](https://recursiveai.org/onenlp/)** — Natural language processing for .NET in C#: tokens, sentences, tags, morphology, lemmas, parses and entities, recognizers in ten languages, language ID for 75, classification and sentence embeddings, with no native code and nothing downloaded at runtime. [Repo](https://github.com/recursive-ai-oss/onenlp-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneNlp)
- **[onespeech](https://recursiveai.org/onespeech/)** — Speech recognition for .NET in C#: transcribe audio, time words, label speakers and run live sessions on open-weight models, with no native inference runtime. [Repo](https://github.com/recursive-ai-oss/onespeech-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneSpeech) · [CLI](https://www.nuget.org/packages/RecursiveAI.OneSpeech.Cli)

### Graphics and sound

- **[oneimage](https://recursiveai.org/oneimage/)** — Thumbnails, crops and conversions on a lazy, tiled engine, with add-ons for text, ASP.NET Core, SVG, PDF and PSD. [Repo](https://github.com/recursive-ai-oss/oneimage-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneImage)
- **[onefont](https://recursiveai.org/onefont/)** — Load TrueType and OpenType fonts and shape text in complex scripts, with bidi, line breaking and fallback. [Repo](https://github.com/recursive-ai-oss/onefont-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneFont)
- **[oneshader](https://recursiveai.org/oneshader/)** — HLSL in; SPIR-V, Metal Shading Language and WGSL out, with reflection, compiled during `dotnet build`. [Repo](https://github.com/recursive-ai-oss/oneshader-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneShader)
- **[oneaudio](https://recursiveai.org/oneaudio/)** — Decode, encode, resample, mix and analyze audio, plus playback and recording. Built first for game audio. [Repo](https://github.com/recursive-ai-oss/oneaudio-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneAudio)
- **[onemedia](https://recursiveai.org/onemedia/)** — Read, write and edit media containers in pure C#: reads MP4/MOV/3GP, Matroska/WebM, MPEG-TS/PS, AVI/DV, ASF, FLV, Ogg, FLAC, MP3 and WAV/AIFF/CAF (tracks, packets, codec headers, tags, capture time, place, device and rotation); writes MP4 and Matroska/WebM, remuxes with a loss report, trims, splits and concatenates without re-encoding, edits tags, and checks or fixes browser playability. Previews: subtitles and captions, capture-date writes, timed telemetry, MPEG-TS and WAV writing, HLS and DASH packaging and sources (no validator has passed the output), index repair and truncated-MP4 reconstruction (with listed limits), and a privacy strip for listed location and device fields (not proof that a file is clean). It decodes no video; audio goes to oneaudio. [Repo](https://github.com/recursive-ai-oss/onemedia-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneMedia) · [Audio](https://www.nuget.org/packages/RecursiveAI.OneMedia.Audio) · [Tool](https://www.nuget.org/packages/RecursiveAI.OneMedia.Tool)

### Games and simulation

- **[onegame](https://recursiveai.org/onegame/)** — A C#-native game engine with no editor: a game is plain C# plus text assets, built, run, tested and exported from the command line. [Repo](https://github.com/recursive-ai-oss/onegame) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneGame.Sdk)
- **[onemath](https://recursiveai.org/onemath/)** — Deterministic math: vectors, matrices, correctly rounded functions, exact geometric predicates and a fixed-point bridge, with the same bits on every platform. [Repo](https://github.com/recursive-ai-oss/onemath-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneMath)
- **[onepath](https://recursiveai.org/onepath/)** — Pathfinding and navigation: grids, graphs, navigation meshes and crowds, with results that are bit-identical on every platform. [Repo](https://github.com/recursive-ai-oss/onepath-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OnePath)
- **[onephysics](https://recursiveai.org/onephysics/)** — Deterministic 2D and 3D physics: rigid bodies, joints, ropes, cloth, soft bodies, fluids, vehicles and ragdolls, with the same world state bit for bit on every platform, and byte-exact snapshots for rollback and lockstep. [Repo](https://github.com/recursive-ai-oss/onephysics-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OnePhysics)
- **[onescope](https://recursiveai.org/onescope/)** — A viewer for deterministic libraries: open a scene, snapshot or replay, or attach to a running program, then scrub its history, inspect any entity, compare runs and fork from any frame. The onephysics and onepath modules are bundled. [Repo](https://github.com/recursive-ai-oss/onescope-csharp) · [NuGet](https://www.nuget.org/packages/RecursiveAI.OneScope.Tool)
